# GCP Google Chat App Setup

[![Open in Cloud Shell](https://gstatic.com/cloudssh/images/open-btn.svg)](https://shell.cloud.google.com/cloudshell/open?cloudshell_git_repo=https://github.com/danish-sheetgo/gcp-chat-setup&cloudshell_git_branch=main&cloudshell_workspace=.&cloudshell_tutorial=tutorial.md&show=ide%2Cterminal)

Creates a Google Cloud project, enables the Google Chat API, and creates a
service account. Chat app configuration is console-only and cannot be scripted;
the setup script prints a direct link to that page.
